# Sado o'chirildi

Sado'dan foydalanganingiz uchun rahmat. Nima yoqmadi yoki nima yetishmadi? Bir-ikki qatorda yozing — keyingi
versiyada tuzatamiz.

**[Telegram'da yozish: t.me/sado_support_bot](https://t.me/sado_support_bot)**

Masalan: "Udemy'da subtitr chiqmadi", "ovoz kechikdi", "API key olish qiyin bo'ldi".

Kengaytma o'chirilganda hech qanday ma'lumot yuborilmadi: brauzer faqat shu sahifani ochdi. Qaytmoqchi
bo'lsangiz: [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/gjpapdekmcjbifpelcdplpoiocmgmknc) · [Chrome Web Store](https://chromewebstore.google.com/detail/mmjajpodjkpgnaekkonbdjkpecogidal).

**English.** Sado was removed. What went wrong or was missing? Write a line on [Telegram](https://t.me/sado_support_bot).
No data was sent when the extension was removed.

**Русский.** Sado удалён. Что не понравилось или чего не хватило? Напишите пару слов в [Telegram](https://t.me/sado_support_bot).
При удалении никакие данные не отправлялись.
