# Sado — политика конфиденциальности

Последнее обновление: 3 октября 2026 г. Другие языки: [O'zbekcha](PRIVACY.uz.md), [English](PRIVACY.en.md).

Sado — расширение браузера, которое переводит английские субтитры видеокурсов на узбекский язык и показывает их
узбекскими субтитрами поверх видео или озвучивает их по-узбекски синхронно с видео.

## Кратко

- В Sado нет аналитики, телеметрии, рекламы и кода отслеживания. У автора нет сервера: Sado ничего не отправляет нам.
- Данные уходят только в перечисленные ниже сервисы, которые вы выбрали сами, — и только после того, как вы дадите
  согласие при настройке сервиса перевода.
- Ваши API-ключи, настройки и кэш переводов хранятся только в этом профиле браузера.

## Кто и что получает

| Получатель | Когда | Что отправляется |
|---|---|---|
| **Один** сервис перевода, выбранный в настройках: Google (Gemini API), Anthropic, OpenAI, OpenRouter или Groq | Когда урок переводится | Английский текст субтитров текущего урока (предложения и соседние с ними предложения), термины из вашего глоссария, которые должны остаться без изменений, список технических терминов для изучения произношения и название модели. Запрос идёт напрямую в API сервиса с вашим API-ключом |
| Microsoft — онлайн-голоса браузера Edge («Online (Natural)»: Sardor, Madina) | Когда онлайн-голос Edge озвучивает урок | Узбекские предложения перевода. Edge отправляет их в облачный сервис Microsoft для озвучивания |
| Microsoft — Azure Speech | Только если в настройках выбран движок «Azure» | Узбекские предложения перевода, с вашим ключом Azure, на `<регион>.tts.speech.microsoft.com` |
| Сайт урока (Udemy, master.dev или включённый вами сайт) | При загрузке субтитров | На Udemy сначала запрос к собственному API Udemy на том же сайте, с вашей сессией Udemy, как это делает сама страница урока: название текущего урока и список его файлов субтитров. Затем расширение скачивает с этого сайта, без cookie, файл субтитров, указанный Udemy для урока или запрошенный самой страницей урока |

Проверки на странице настроек («Ulanishni tekshirish» — проверка подключения, «Ovozni eshitish» — прослушивание голоса,
прослушивание произношения) отправляют в соответствующий сервис только тестовый текст или введённое вами слово —
не текст урока. Список моделей запрашивается у выбранного сервиса перевода с вашим сохранённым ключом; в этом
запросе нет никакого текста.

Каждый сервис обрабатывает полученные данные по своим условиям и политике конфиденциальности.

**Бесплатный тариф Gemini.** На бесплатном тарифе Google может использовать отправленный текст для улучшения своих
продуктов. Gemini API могут использовать только лица старше 18 лет. Подробнее:
[дополнительные условия Gemini API](https://ai.google.dev/gemini-api/terms). Если вы этого не хотите, выберите
платный тариф, который не использует данные для обучения, или другой сервис.

## Согласие

Согласие даётся при настройке сервиса перевода: на странице приветствия и в настройках прямо над кнопкой
«Roziman — saqlash va tekshirish» (Согласен — сохранить и проверить) сказано, что субтитры урока уходят выбранному
сервису, а узбекский текст для озвучки — Microsoft. Согласие относится только к выбранному сервису: при переключении
на другой оно запрашивается снова. Если согласия нет (например, сервис сменился или изменился список получателей),
панель показывает короткий запрос с кнопкой «Roziman» (Согласен); пока вы её не нажмёте, ничего не отправляется.
Полный список (получатели, что остаётся на устройстве, условия Gemini) — в разделе «Maxfiylik» (Конфиденциальность)
страницы настроек. Согласие (версия, сервис и дата) хранится на этом устройстве. Его можно отозвать в любой момент:
Настройки → «Maxfiylik» → «Rozilikni qaytarib olish» (Отозвать согласие). После этого текст урока никуда не
отправляется, а перевод и озвучка в открытых уроках сразу останавливаются.

## Что хранится на устройстве

В хранилище расширения браузера (`chrome.storage.local`), только в этом профиле браузера. Ничего не
синхронизируется с другими устройствами.

- **API-ключи** (сервис перевода, Azure) — в фоновой части расширения. Ни веб-страница, ни скрипт расширения на
  странице не могут их прочитать.
- **Настройки** — выбранный сервис и модель, движок и выбранный голос, регион Azure, режим панели
  (выключено / субтитры / озвучка) и вид субтитров, запись о согласии.
- **Словари** — ваши термины и произношения, а также произношение терминов, полученное от сервиса перевода.
- **Кэш переводов** — для каждого урока: идентификатор урока (на включённых вами сайтах — адрес страницы) и название,
  английский текст субтитров, узбекский перевод, тайминги и то, какая модель переводила. Кэш нужен, чтобы при
  повторном открытии урока не платить сервису снова.
- **Журнал диагностики** — код последних 50 ошибок (например `auth`, `timeout`), вид работы (перевод, субтитры,
  голос, список моделей), время, длительность и количество. Текст субтитров, переводы и ключи в него не
  записываются. Сам журнал никуда не отправляется: «Diagnostikani nusxalash» (скопировать диагностику) в
  настройках копирует его вместе с версией расширения, названием браузера, сервисом и моделью и состоянием
  голоса, а кому отправить — решаете вы.
- **Скорость моделей** — для последних 20 пар «сервис и модель»: среднее число выходных токенов в секунду,
  число замеров и время последнего. Текст не сохраняется. Входит в «Diagnostikani nusxalash» (без времени) и сам
  никуда не отправляется.

Временно (`chrome.storage.session`, очищается при закрытии браузера): адрес, тип и страница-источник файлов
субтитров, запрошенных страницей урока, и запросов, помогающих найти адрес субтитров (например, данные урока
master.dev), — не более 50 на вкладку. Записи вкладки удаляются при её закрытии. Другие запросы расширение не
сохраняет и никакие запросы не блокирует и не изменяет.

## Как удалить

- **Кэш переводов:** Настройки → «Kutubxona» (Библиотека) → кнопка удаления у урока (один урок) или
  «Hammasini o'chirish» (Удалить все).
- **Ключ сервиса перевода:** Настройки → «Tarjima» (Перевод) → «API key» → «O'chirish» (Удалить).
- **Всё** (в том числе ключ Azure, словари, изученные произношения и согласие): удалите расширение из браузера —
  браузер удалит и все его локальные данные.
- Данные на стороне сервисов удаляются по политике соответствующего сервиса.

## Не продаём и не передаём

Sado не продаёт данные, не использует их для рекламы и не передаёт никому, кроме названных выше сервисов, выбранных
вами. Данные используются только для единственной задачи расширения — перевода и озвучивания субтитров. Sado
соблюдает политику Chrome Web Store в отношении пользовательских данных, включая требования Limited Use.

## Дети

Sado не предназначен для детей младше 13 лет. Для использования Gemini API требуется возраст 18 лет.

## Изменения

При изменении политики этот документ обновляется. Если изменится список получателей, расширение снова попросит
согласия перед первым запросом к новому получателю.
